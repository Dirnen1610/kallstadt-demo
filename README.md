# Kallstadt : démo jouable

Kallstadt est un RPG de ferme et de survie en coopération (1 à 4 joueurs). Le jeu se passe dans une ville fortifiée du Palatinat, en 1510, sous la Tour des vampires. Le jour, on cultive, on commerce et on parle aux habitants. La nuit, on rentre avant le couvre-feu.

## Télécharger

**Version 1.29 (Jeanne, le fléau)**, en un seul téléchargement : [main.zip](https://github.com/Dirnen1610/kallstadt-demo/archive/refs/heads/main.zip). Le décompresser, puis double-cliquer sur `v1.29/assembler.bat` : il recolle les morceaux, décompresse le jeu et le lance. Détails dans [`v1.29/LISEZMOI.md`](v1.29/LISEZMOI.md).

Les versions jusqu'à la 1.27 sont dans l'onglet **Releases** à droite ([dernière publiée](https://github.com/Dirnen1610/kallstadt-demo/releases/latest)).

## Lancer

1. Décompresser le zip dans un dossier. Ne pas lancer le jeu depuis l'intérieur du zip.
2. Double-cliquer sur `Kallstadt.exe`. Il faut Windows 10 ou 11 en 64 bits et une carte graphique compatible Vulkan.
3. Le jeu n'est pas signé, donc Windows SmartScreen peut afficher « Windows a protégé votre ordinateur ». Cliquer sur **Informations complémentaires**, puis sur **Exécuter quand même**.

## Touches

| Touche | Action |
|---|---|
| ZQSD / Maj | se déplacer / courir |
| Espace | esquiver, dialogue suivant |
| Clic gauche / clic droit | frapper / coup spécial |
| F | parler, entrer, utiliser |
| R | planter, manger, boire, torche |
| 1 à 0 | cases de la barre d'objets |
| Tab (maintenu) | roue des outils et de l'épée ; appui bref : objet précédent |
| A | boire une fiole |
| E · X · V | prières : Abraham, Bible en main (Vade retro, Aspersion, Cercle de sel) ; Jeanne, épée en main (Lame de lumière, Deus vult, Terre consacrée) |
| B / L | construire / volets |
| M | raccourcis de la démo : aller tout de suite au château de Dracula, à ses Épouses ou aux boss de la mine |
| Échap · I · C · J · T | pause · sac · personnage · quêtes · maîtrises |

Le zip contient aussi un `LISEZMOI.txt` avec ces mêmes indications.
